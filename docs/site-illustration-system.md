## State behavior

- A quote, itinerary, destination or experience action retains the correct message and original campaign reference.
- With the confirmed business number configured, the action opens WhatsApp synchronously and shows “Your plans, ready to send.” The traveller must send the message in WhatsApp. The dialog provides a retry link and a copy action.
- Without a number, the illustrated enquiry preview explains that nothing has been sent and lets the visitor review and copy the message.
- Clipboard success changes the artwork and heading to “Your enquiry is copied.” A failed clipboard write shows recovery instructions and never shows success. A new enquiry resets the previous copy state.
- Catalogue searches combine with the existing region or interest filter. No matches shows an illustrated state with a reset action and a contextual enquiry. Reset clears both the query and filter, and returns focus to the search field.
- Unknown URLs retain HTTP 404 and provide working home and enquiry actions.
- No state claims that a booking, payment or enquiry delivery has been confirmed by the website.
